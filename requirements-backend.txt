# =====================================================================
# Runtime-only dependencies for backend/agent.py + backend/main.py.
#
# This is intentionally NOT the same as requirements.txt at the repo
# root. requirements.txt is your full dev environment (Jupyter,
# matplotlib, shap, beautifulsoup4, yfinance for notebooks, etc.) --
# fine for local development, but most of it is never imported by the
# running API. Installing the full requirements.txt inside the Docker
# image would drag in ~100 unrelated notebook packages (JupyterLab,
# ipykernel, etc.), bloating build time and image size for nothing.
#
# What's deliberately left OUT of this file, and why:
#   - shap            -> only used in 08_model_training.ipynb to
#                         *generate* data/models/shap/shap_importance.csv.
#                         agent.py only reads that CSV with pandas.
#   - matplotlib/seaborn -> only used for notebook plots.
#   - beautifulsoup4, requests -> only used for Week 5 news scraping.
#   - vaderSentiment  -> only used in 06_sentiment_analysis.ipynb as a
#                         secondary/comparison sentiment method; the
#                         agent reads the precomputed FinBERT scores
#                         from data/sentiment/news_with_sentiment.csv.
#
# If agent.py or main.py start importing something new, add it here too.
# =====================================================================
